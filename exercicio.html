História do GitHub

O GitHub foi fundado em abril de 2008 por Tom Preston-Werner, Chris Wanstrath, PJ Hyett e Scott Chacon. Ele rapidamente se tornou a maior plataforma de hospedagem de código-fonte do mundo, permitindo que desenvolvedores colaborassem em projetos utilizando o sistema de controle de versão Git.

Em 2018, o GitHub foi adquirido pela Microsoft por US$ 7,5 bilhões, marcando um grande passo na integração de ferramentas de desenvolvimento com serviços corporativos.

Hoje, o GitHub é usado por milhões de desenvolvedores e empresas para criar, compartilhar e colaborar em projetos de software, desde pequenos scripts até grandes sistemas corporativos.
